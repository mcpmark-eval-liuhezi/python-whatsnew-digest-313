# python-whatsnew-digest-313

Notes and handouts for our study group's Python 3.13 unit. This repository distills the official **"What's New In Python 3.13"** release notes into a compact digest of the highlights and deprecations, so the group can start the unit knowing what actually changed in the language compared to 3.12.

- Read the digest: [python-3.13-digest.md](python-3.13-digest.md)

The digest is added through a reviewed pull request rather than being committed straight to the default branch, so each handout gets a teammate's sign-off before it lands.
